# EduMindCare - Learning Management System

## 📌 Project Overview
EduMindCare is a Learning Management System designed for universities and institutes.

## 👤 User Roles
- Admin
- Teacher
- Student

## 🔑 Key Features
### Admin
- Add lectures
- Assign subjects to teachers
- Manage users

### Teacher
- Create quizzes
- View student feedback
- Manage subjects

### Student
- Submit feedback for teachers
- Attempt quizzes
- View assigned subjects

## 🛠 Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / PHP / Java (edit this)
- Database: MongoDB / MySQL
- Tools: VS Code
